教材ポータル

受講しているコースの教科書を選んでね。家からでもスマホからでも、いつでも読めます。

Webコース

全6回 Webコース教科書（HTML / CSS / JavaScript）
自分のWebサイトをゼロから作る。最後は3択クイズアプリを完成させて発表！

Unityコース

全6回 Unityコース教科書（Platformer Microgame版）
完成済みの2Dアクションゲームを改造して、自分だけの作品に仕上げる

今回の講習ではこちらを使います。まずは第0章（事前準備）を家で進めておいてね。

自由研究用 Unityコース教科書（2D Game Kit版）
Unity公式の2D Game Kitで、主人公エレンが冒険する自分だけのステージを作る

こちらは講習では扱いませんが、自分でアセットを追加してもっと作り込みたい人向けに公開しています。

GDevelopコース

全6回 GDevelopコース教科書（2D横スクロールアクション）
ブラウザだけで使えるゲームエンジンで、アクションゲームをゼロから1本作る（英語UI版）
 全6回 GDevelopコース教科書 日本語UI版
同じゲームを、GDevelopの画面を日本語にして作る版。ノーコードでゲームを作ることに集中したい人向け
 全6回 GDevelopコース教科書（3Dアクション編）
3Dの街でトラックに乗り、銃でゾンビと戦うゲームを作る（公式コース「Make a 3D GTA Game」が元。英語UI版）
 全6回 GDevelopコース教科書（3Dアクション編 日本語UI版）

 全6回 GDevelopコース教科書（ローグライク編）
ダンジョンでナイフを投げてゴブリンを倒し、ウェーブを生きのびるゲームを作る（公式コース「Make a Roguelike Game」が元。英語UI版）
 全6回 GDevelopコース教科書（ローグライク編 日本語UI版）
同じローグライクゲームを、GDevelopの画面を日本語にして作る版

英語UI版と日本語UI版は、できあがるゲームが同じです。
公式ドキュメントを読んだり、あとで本格的にプログラミングしたりするなら英語UI版がおすすめです。
