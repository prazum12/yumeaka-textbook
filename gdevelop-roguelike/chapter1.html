第1章

プレイヤーを動かそう

📅 第1回の講習で使います（日付が決まったらここに記載）
💻 使っているPC:

🎯 この章でできるようになること

  • アセットストアの素材で、キャラクターの見た目を入れかえられる
  • 動いているかどうかで、アニメーションを切りかえられる
  • マウスの位置（CursorX、CursorY）をイベントで使える
  • クリックしたらナイフを作って、マウスのほうへ飛ばせる

1-1. この章で作るしくみ

この章で作るルール（まとめ）
条件歩いている
アクション走るアニメーションにする
条件歩いていない
アクション立っているアニメーションにする
条件マウスがプレイヤーより左にある
アクション左を向く（左右反転）
条件左クリックをはなした
アクションナイフを作って、マウスのほうへ飛ばす
条件ナイフがプレイヤーから遠くなった
アクションナイフを消す

1-2. トップダウンのスターターから作ろう

今回は「Top-down」（真上から見下ろす）のスターターから始めます。
歩く・壁にぶつかる・カメラがついてくる、といった基本はもう入っています。
そこに、騎士の見た目やナイフ、敵を足していきます。

1新しいゲームの画面を開く

https://editor.gdevelop.io を開いて、ログインしていることを確かめます。
ホーム画面の左のメニューで「Create」を選び、右の「＋ Create new game」を押します。
「Continue with Human Intelligence」の列から「Top-down」を選ぼう。

2プロジェクト名を付けて作成する

「Project name」の欄に my-dungeon と入力します。
保存先が「GDevelop Cloud」になっていることを確かめて、「Create new game」を押します。

「Maximum of 3 cloud projects reached」と出て作れないときは、第0章「4本目のゲームを作りたくなったら」を見てね。

3スターターの中身を見る

エディタが開くと、まん中にステージが見えます。
右の「Objects」の一覧に、Player（プレイヤー）、Ground_Tilemap（床）、Plant_Obstacle（草のかべ）、Wall_Obstacle（石のかべ）などがあります。
上の「Preview」を押すと、矢印キーでプレイヤーを歩かせられます。
少し遊んだら、ゲームのタブを閉じてエディタにもどろう。

1-3. プレイヤーを騎士にしよう

4Dungeon のパックを開く

「Objects」の「＋」を押して、アセットストア（素材のお店）を開きます。
検索欄に dungeon と入れて、「Dungeon」（作者: Robert Norenberg (0x72)）のパックを開きます。
ライセンスは「CC0 (public domain)」なので、自由に使えます。
Character のなかに、騎士やゴブリンなどのキャラがたくさん入っています。

5Swap assets で Player の見た目を入れかえる

いったん「Close」で閉じます。
一覧の Player の「⋮」から「Swap assets」（素材を入れかえる）を選びます。
検索で knight male と入れて「Knight Male」を選び、「Swap」を押します。
名前は Player のまま、見た目だけ騎士になります。
アニメーションは「Idle」（立つ）「Run」（走る）「Hit」（ダメージ）の3つです。

Swap assets … 名前やイベントはそのままで、見た目（画像）だけを別の素材に入れかえる機能。
あとから「やっぱりこのキャラがいい」と思ったときも、これを使えば作り直さなくてすみます。
6向きが回らないようにする

シーンの騎士をクリックすると、左に Player のプロパティが出ます。
「TopDownMovement」のところの「Rotate object」をOFFにします。
ONのままだと、歩く方向に合わせて騎士がくるくる回ってしまいます。
このゲームでは、左右の向きはあとで「反転」で作ります。

7ナイフを追加する

もう一度「＋」から Dungeon のパックを開き、「Weapon」の中の「Knife」を選んでプロジェクトに追加します。
ナイフはイベントで作り出すので、シーンに置かなくてOK。
もし置いてしまったら、シーンのナイフをクリックして Delete キーで消しておこう。

1-4. 歩くアニメーションと向きをつけよう

上のタブの「Game Scene (Events)」を開きます。
スターターのイベント（プレイヤーをかべから押しもどすイベント）は、消さずにそのまま残しておきます。
右下の「+ Add...」→「Event group」で、新しいグループ Player を作ります。
グループをクリックしてから Shift + D を押すと、グループの中にイベントができます。

8歩いているときは Run、止まっているときは Idle

条件は is moving で検索 →「Is moving」（Top-down movement のもの）、Object は Player。
アクションは animation by name で検索 →「Animation (by name)」で Player を「Run」。

イベントをクリックして Shift + A で下に新しいイベントを作ります。
条件はまた「Is moving」で Player にして、下の「Invert condition」（条件を反対にする）をONにします。
アクションは「Animation (by name)」で「Idle」。

9マウスのほうを向く

新しいイベントを作り、条件に compare two numbers で検索 →「Compare two numbers」を入れます。
First expression に CursorX()、Sign は「< (less than)」、Second expression に Player.CenterX()。
「マウスのXが、プレイヤーのまん中より小さい」＝「マウスが左にある」という意味です。

アクションは flip で検索 →「Flip the object horizontally」、Player を「Yes」（反転する）。
もう1つイベントを作り、Sign を「≥ (greater or equal to)」にして、Flip を「No」にします。

CursorX() … マウスのカーソルが、ステージのどこにあるか（X座標）を教えてくれる式。
Y座標は CursorY() です。
Player.CenterX() は、プレイヤーのまん中のX座標です。

1-5. ナイフを投げよう

新しいグループ Knife を作り、その中にイベントを作ります。

10クリックしたらナイフを作る

条件は mouse button released で検索 →「Mouse button released」、ボタンは「Left (primary)」。
アクションは4つです。

  • create an object で検索 →「Create an object」、Knife を X Player.CenterX()、Y Player.CenterY() に作る
  • angle で検索 →「Angle」、Knife を下の式にする
  • move toward a position で検索 →「Add a force to move toward a position」、Knife、X CursorX()、Y CursorY()、Speed 600、下は「Permanent」
  • scale で検索 →「Scale」、Knife を 3（3倍の大きさ）
Knife の Angle
Knife.AngleToPosition(CursorX(), CursorY()) + 90
+ 90 のわけ … AngleToPosition は「ナイフからマウスへの向き」を角度で教えてくれます。
でも Knife の画像は、もともと上を向いています。
そのままだと横向きに飛んでしまうので、90度足して、刃先がマウスのほうを向くようにしています。
11遠くへ行ったナイフを消す

新しいイベントを作り、条件に「Distance between two objects」で Knife と Player、距離 600。
「Invert condition」をONにして「600 より遠い」にします。
アクションは「Delete the object」で Knife。

12保存して Preview

Ctrl + S（Macは Cmd + S）で保存してから Preview します。
矢印キーで歩くと走るアニメーションになり、止まると立つアニメーションにもどります。
マウスを左右に動かすと、騎士がマウスのほうを向きます。
クリックするたびに、マウスのほうへナイフが飛んでいけば成功！

💪 やってみよう

ナイフの速さ（600）や大きさ（3）を変えてみよう。
Weapon フォルダのほかの武器（斧やハンマーなど）にかえるのもおもしろいよ。

ヒント

Knife の「⋮」から「Swap assets」を使うと、名前はそのままで見た目だけ入れかえられます。
向きがずれたら、Angle の式の「+ 90」を「+ 45」などに変えてみよう。

1-6. 🚨 つまずきポイント集

騎士がくるくる回る

原因: TopDownMovement の「Rotate object」がONのまま。

直し方: シーンの騎士をクリックして、Rotate object をOFFにしよう。

ナイフが横向きに飛ぶ

原因: Angle の式に「+ 90」がない。

直し方: 式が Knife.AngleToPosition(CursorX(), CursorY()) + 90 になっているか確かめよう。

ナイフが出るけど動かない

原因: フォースが「Instant」になっている。

直し方: 「Add a force to move toward a position」を開いて、「Permanent」を選びなおそう。

左右の向きが逆になる

原因: 「Yes」と「No」が反対になっている。

直し方: マウスが左（<）のときに Yes、右（≥）のときに No になっているか確かめよう。
