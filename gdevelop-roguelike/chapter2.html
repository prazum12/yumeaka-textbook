第2章

敵がおそってくる

📅 第2回の講習で使います（日付が決まったらここに記載）
💻 使っているPC:

🎯 この章でできるようになること

  • 敵をプレイヤーのほうへ動かせる
  • オブジェクト変数で、敵1体ずつに体力を持たせられる
  • ぶつかったこと（Collision）を条件にできる
  • タイマーとランダムで、敵をどんどん出せる

2-2. ゴブリンを用意しよう

1ゴブリンを追加する

「Objects」の「＋」から Dungeon のパックを開き、Character の中の「Goblin」を選んでプロジェクトに追加します。
アニメーションは「Idle」と「Run」の2つです。
ゴブリンはイベントで作り出すので、シーンには置かなくてOK。

2ゴブリンに体力（オブジェクト変数）を持たせる

一覧の Goblin をクリックします。
左の「Object Variables」の「＋」で変数を作り、名前を Health、型は「Number」、値を 2 にします。
ナイフ2回で倒れるゴブリンになります。

オブジェクト変数 … オブジェクト1つ1つが、べつべつに持っている変数。
ゴブリンが10体いたら、10体それぞれが自分の Health を持っています。
だから、ナイフが当たったゴブリンだけ体力がへります。

2-3. ゴブリンが追いかけてくる

イベントシートで新しいグループ Enemy を作ります。

3プレイヤーのほうへ動かす

条件のないイベントを作ります（条件は空のままでOK）。
アクションは2つです。

  • move toward で検索 →「Add a force to move toward an object」、Object は Goblin、Target は Player、Speed は 100、下は「Instant」のまま
  • 「Animation (by name)」で Goblin を「Run」
条件のないイベント … 条件を入れないと、「いつも」（1秒に60回くらい）アクションが動きます。
Instant の力を毎回かけるので、ゴブリンはずっとプレイヤーを追いかけ続けます。
4ゴブリンの向きを変える

新しいイベントの条件に、X position で検索 →「X position」を入れます。
Object は Goblin、Sign は「> (greater than)」、値は Player.X()。
アクションは「Flip the object horizontally」で Goblin を「Yes」。

もう1つイベントを作り、Sign を「≤ (less or equal to)」、Flip を「No」にします。
ゴブリンがいつもプレイヤーのほうを向くようになります。

2-4. ナイフで倒そう

5ナイフが当たったら体力をへらす

新しいイベントの条件に、collision で検索 →「Collision」（General › Objects の、いちばん上のもの）を入れます。
1つ目の Object は Knife、2つ目は Goblin。

アクションは2つです。

  • 「Delete the object」で Knife
  • change object variable value で検索 →「Change object variable value」、Object は Goblin、Variable は Health、Modification's sign は「- (subtract)」（引く）、Value は 1
6体力が0になったら消す

新しいイベントの条件に、object variable value で検索 →「Object variable value」。
Object は Goblin、Variable は Health、Sign は「≤ (less or equal to)」、値は 0。
アクションは「Delete the object」で Goblin。

2-5. ゴブリンをどんどん出そう

72秒ごとにゴブリンを作る

新しいイベントの条件に、scene timer で検索 →「Value of a scene timer」。
Timer's name は "EnemyTimer"（ダブルクォーテーションごと入れる）、Sign は「≥ (greater or equal to)」、Time は 2。

アクションは3つです。

  • start (or reset) a scene timer で検索 →「Start (or reset) a scene timer」、"EnemyTimer"（0にもどす）
  • 「Create an object」で Goblin を、下の式の場所に作る
  • 「Scale」で Goblin を 3
X position
RandomInRange(200, 1100)
Y position
RandomInRange(150, 600)
RandomInRange(200, 1100) … 200 から 1100 までの中から、ランダムに（でたらめに）1つ数を選ぶ式。
毎回ちがう場所にゴブリンが出てきます。
8シーンが始まったらタイマーをスタート

最後に、条件 at the beginning of the scene →「At the beginning of the scene」のイベントを作ります。
アクションは「Start (or reset) a scene timer」で "EnemyTimer"。
これがないとタイマーが動かず、ゴブリンが1体も出てきません。

9保存して Preview

保存してから Preview します。
2秒ごとにゴブリンが出てきて、騎士を追いかけてきます。
ナイフを2回当てると、ゴブリンが消えます。
まだゴブリンにさわってもダメージはありません（第4章で作ります）。

💪 やってみよう

ゴブリンの速さ（100）、体力（2）、出てくる間かく（2秒）を変えて、むずかしさを調整してみよう。

ヒント

速さは「Add a force to move toward an object」、体力は Goblin の Object Variables、間かくはタイマーの条件の数字です。

2-6. 🚨 つまずきポイント集

ゴブリンが1体も出てこない

原因: 「At the beginning of the scene」でタイマーをスタートしていない、またはタイマーの名前がちがう。

直し方: 2か所とも "EnemyTimer" になっているか、大文字・小文字まで確かめよう。

ゴブリンがとても小さい

原因: 作ったあとの「Scale」を入れていない。

直し方: Create an object のすぐ下に「Scale」で 3 を入れよう。

ナイフが当たっても倒れない

原因: Health をシーン変数に作ってしまった、または「Object variable value」ではなく「Variable value」を使った。

直し方: 一覧の Goblin をクリックして、左の Object Variables に Health（2）があるか確かめよう。
