第4章

ゾンビがやってきた

📅 第4回の講習で使います（日付が決まったらここに記載）
💻 使っているPC:

🎯 この章でできるようになること

  • 敵を主人公のほうへ向かせて、追いかけさせられる
  • 3Dモデルのアニメーションを名前で切りかえられる
  • 体力（HP）を変数で数えて、少しずつ減らせる
  • UIレイヤーに文字を置いて、HPを画面に出せる

4-1. この章で作るしくみ

街にゾンビを3体置いて、主人公を追いかけてくるようにします。
ゾンビにくっつかれている間は、主人公の HP（体力）がどんどん減っていきます。

この章で作るルール（まとめ）
条件（なし＝いつでも）
アクションゾンビを主人公のほうへ向ける
条件ゾンビが主人公から遠い
アクションゾンビを主人公のほうへ動かす
歩くアニメーションにする
条件ゾンビが主人公に近い
乗っていない
アクションパンチのアニメーションにする
HP を少しずつ減らす
条件（なし＝いつでも）
アクション画面の文字を「HP: 〇〇」にする

4-2. ゾンビを置こう

1ゾンビを追加する

「Objects」の「＋」から「Zombie Apocalypse」のパックを開き、「Character」のフォルダを開きます。
緑色の「Zombie Basic」を選んで「Add to the scene」を押します。
（上の検索欄に zombie basic と入力しても見つかります。）

2名前を Zombie にして、大きさを決める

一覧に「Zombie_Basic」ができます。
右の「⋮」を押して「Rename」を選び、名前を Zombie にして Enter。
次に Zombie をクリックして、左の「Default size」の Width・Height・Depth を全部 70 にします。
主人公（高さ60）より少し大きいくらいです。

名前を変えるときの注意

名前の欄が入力できる状態になっていないのにキーを押すと、そのキーが「ショートカット」として動いてしまいます。
パネルが閉じたり、ほかのものが選ばれたりしたら、あわてずに Rename からやり直そう。

3ゾンビを3体置く

一覧の Zombie を、シーンの草原にドラッグします。
主人公から少しはなれた場所に、3回くり返して3体置こう。
上から見ると小さく見えますが、それで大丈夫です。

4-3. HP を用意しよう

4HP の変数を作る

シーンの何もないところをクリックすると、左に「Game Scene」のプロパティが出ます。
「Scene Variables」の右の、四角から矢印が出たマークを押します。
「Add variable」を押して、名前を PlayerHealth、型は「Number」（数）のまま、値を 100 にして「Apply」。

5UI 用のレイヤーを作る

HP の文字は、カメラが動いても画面の左上にずっと表示させたいです。
そこで、カメラが動いても画面に貼りついたままの層、レイヤーを作ります。
画面右上のボタンの列にある、紙が重なったマークのボタンを押すと、右下に「Layers」のパネルが開きます。
パネルの右上の「＋」を押して、名前を UI にします。
そのあと、UI の行の右にある「○」を押して、●にします。
●がついたレイヤーに、これから置くものが入ります。

レイヤー … 透明なシートを何枚も重ねたようなしくみ。
街やゾンビは下のシート（Base layer）、HP の文字は上のシート（UI）に描くイメージ。
カメラが動かすのは下のシートだけなので、UI の文字は画面の同じ場所に出続けます。
最初からある「MobileControls」は、スマホ用のボタンを置くためのレイヤーです。
6HP の文字を作る

「＋」から「New object from scratch」を開き、text で検索して「Text」を選びます。
次のように設定して「Apply」を押します。

  • Object name: HealthText
  • Size: 36、Bold にチェック
  • Initial text to display: HP: 100
  • Outline の Enabled にチェック、Thickness: 4（白いふちどりで読みやすくなる）
7HP の文字を画面の左上に置く

一覧の HealthText を、シーンの中の四角い線（ゲーム画面のはんい）の中にドラッグします。
置いた文字をクリックして、左の X を 20、Y を 110 にします。
レイヤーの欄が「UI」になっていればOK。
最後に、Layers パネルの「Base layer」の「○」を押して、●を Base layer にもどしておこう。

4-4. ゾンビを動かすイベントを作ろう

イベントシートで、新しいグループ Zombie を作ります（「+ Add...」→「Event group」）。
グループをクリックしてから Shift + D で、中にイベントを作ります。

グループ名の最後に「d」がついてしまった

名前を入力している途中で Shift + D を押すと、「Zombied」のように文字が入ってしまいます。
Backspace で消して Enter で決めてから、もう一度 Shift + D を押そう。

8ゾンビを主人公のほうへ向ける

条件はなし。
アクションに rotate toward position で検索して「Rotate toward another object」（ほかのオブジェクトのほうを向く）を選びます。
Object は Zombie、Target object は Player、Angular speed（回る速さ）は 0。
0 にすると、すぐにそっちを向きます。

9遠いときは、歩いて近づく

今のイベントをクリックして Shift + A で、下に新しいイベントを作ります。
条件は「Distance between two objects」で Zombie と Player、距離 50。
「Invert condition」を ON にして、「50 より遠い」にします（第3章の弾と同じ）。

アクションは2つです。

  • force to move toward で検索 →「Add a force to move toward an object」、Object は Zombie、Target は Player、Speed は 80、下は「Instant」のまま
  • animation by name で検索 →「Animation (by name)」、Object は Zombie、Animation name は一覧から「Walk」
Instant と Permanent … 第3章の弾は「Permanent」（ずっと押し続ける）でした。
ゾンビは「Instant」（1回だけ押す）にします。
条件が合っている間は毎回このイベントが動くので、遠い間だけ押され続けて、近づいたら止まります。
10近いときは、パンチで HP を減らす

もう一度 Shift + A で新しいイベントを作ります。
条件は2つ。

  • 「Distance between two objects」で Zombie と Player、距離 50（Invert は OFF のまま＝50 より近い）
  • 「Variable value」で InCar が False（トラックに乗っていない）

アクションも2つ。

  • 「Animation (by name)」で Zombie を「Punch」（パンチ）
  • change variable value で検索 →「Change variable value」、Variable は PlayerHealth、Modification's sign は「- (subtract)」（引く）、Value は下の式
Value（へらす量）
20 * TimeDelta()
TimeDelta() … 前の画面から今の画面までにかかった時間（秒）。
ゲームは1秒に60回くらい画面をかきかえるので、TimeDelta() はだいたい 0.016 です。
20 * TimeDelta() を毎回引くと、ちょうど「1秒で20へる」になります。
PC が速くても遅くても、同じペースでへるのがポイントです。
11HP を画面に出す

もう一度 Shift + A で新しいイベントを作ります。
条件はなし。
アクションの画面で、左の一覧から HealthText を選び、いちばん上の「Text」を選びます。
Modification's sign は「= (set to)」のまま、Text の欄に次の式を入れます。

HealthText に入れる式
"HP: " + ToString(round(PlayerHealth))
round() … 小数を四捨五入して、整数にしてくれる式。
HP は 0.33 ずつのように細かくへるので、そのまま出すと「HP: 87.66666」のようになってしまいます。
12できあがったイベントを確かめる

Zombie グループの中が、下の写真と同じ4つのイベントになっていればOK。

4-5. ためしてみよう

13保存して Preview

保存してから Preview します。
左右からゾンビが歩いてきて、主人公に近づくとパンチを始めます。
パンチされている間、左上の HP がどんどんへっていきます。
走ってにげたり、トラックに乗ったりしてみよう。

HP がマイナスに？ … 今は HP が 0 になってもゲームは終わらず、マイナスになっていきます。
次の章で、ゲームオーバーのしくみを作ります。

💪 やってみよう

ゾンビの速さ（80）や、HP のへる量（20）を変えて、ちょうどいいむずかしさにしてみよう。
ゾンビをもっとたくさん置いてみるのもおもしろいよ。

ヒント

Character フォルダには「Zombie Chubby」や「Zombie Ribcage」など、ほかのゾンビもいます。
オブジェクトを右クリックして「Swap assets」を使うと、イベントはそのままで見た目だけ入れかえられます。

4-6. 🚨 つまずきポイント集

ゾンビが動かない

原因: 2つ目のイベントの「Invert condition」が OFF になっている。

直し方: 条件をダブルクリックで開いて、Invert condition を ON にしよう。
ON になると、条件の前に赤いマークがつきます。

ゾンビが歩かずにすべってくる

原因: Animation の名前を選んでいない。

直し方: Animation (by name) を開いて、Animation name の一覧から「Walk」を選びなおそう。

HP の文字がカメラといっしょに動いてしまう

原因: HealthText が Base layer に置かれている。

直し方: 置いた HealthText をクリックして、左のレイヤーの欄を「UI」に変えよう。

HP の文字が出ない・「HP: 100」から変わらない

原因: 4つ目のイベントの式がまちがっている、またはそのイベントがない。

直し方: 上の式をコピーして貼りつけなおそう。
"HP: " のダブルクォーテーション（"）を忘れやすいので注意。
